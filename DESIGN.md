# Documentation design

The portal extends Magnascale's established brand in a reading-focused MkDocs Material layout. It uses forest #153f34, cream #f6f5ee, off-white #fffefa, lime #d7ef90, and a locally served Manrope face.

The home page leads with the first-review task, then a compact task directory and real synthetic product screenshot. Guide pages use descriptive headings, sequential instructions, and comparison tables where helpful. Persistent section navigation, on-page contents, browser search, previous/next links, and a mobile drawer support wayfinding.

Body copy uses a comfortable reading measure and clear line spacing. Focus indicators, underlined hover links, contrast, reduced-motion support, image descriptions, and responsive tables are part of the design. No analytics or third-party font requests are added.
