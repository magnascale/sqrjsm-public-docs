# Install and open the app

Service Quality Review is designed for **Jira Service Management Cloud**. Your site needs a service project with requests to review, and reviewers who can access those requests in Jira.

!!! note "Marketplace availability"
    The Marketplace listing is being prepared. An installation link will be added when it is available. These guides describe the accepted product workflow; publishing this documentation does not make the app generally available.

## Installation checklist

When the Marketplace listing is available, an authorized Atlassian administrator will install the app, review the requested permissions, and complete Atlassian's consent and licensing steps.

Before beginning a review program, confirm that:

- The app is installed on the intended Atlassian site and its licence permits new work.
- At least one person has permission to create a program.
- Your reviewers can open the relevant requests and comments in Jira/JSM.
- You have decided which service project and time zone the program should use.

One installation serves one Atlassian site. Reporting across multiple sites is not available.

## Open Service Quality Review

In Jira, choose **Apps → Service Quality Review**.

An app administrator can manage program-creator grants in **App settings → Access**. If you cannot create a program, ask an administrator to check your grant and reopen the app after it is updated.

An administrative grant does not grant access to private reviews. Program membership and Jira permissions are checked separately.
