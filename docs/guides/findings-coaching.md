# Act on findings and share coaching

Findings connect patterns across reviews and periods. Coaching gives an agent a separate, deliberately released summary. Either can be useful without the other.

## Record a finding

In **Results → Findings**, use the available finding workflow to connect relevant submitted reviews and explain the issue that needs attention.

Keep the evidence and the proposed improvement distinct. State what the reviewed requests establish, what remains uncertain, and the practical change you want to make. Linked evidence remains subject to current access and retention.

## Create corrective Jira work

A manager can prepare corrective work from a finding. Inspect the proposed Jira fields and the text you intend to share, then confirm creation. Include only the information appropriate for the destination project; do not copy private evidence into broader Jira work unnecessarily.

The creation is a human-confirmed action. AI suggestions do not create Jira work.

!!! warning "If creation is uncertain"
    Use **Retry** for the same saved operation. This checks for an existing issue without sending another create request. If the state remains uncertain, inspect Jira and contact support before attempting further corrective work. Starting a new operation can create a duplicate.

Track the linked Jira work and update the finding through its supported workflow as the action progresses.

## Release a coaching summary

A manager prepares a separate coaching summary for the reviewed agent, checks the recipient and wording, then deliberately releases it. The recipient reads released feedback in **My coaching**.

Releasing coaching does **not** make the underlying private review visible to that agent. A reviewed-agent roster entry alone grants no private QA access.

A manager can revoke a release. Revocation prevents further authorized access through the app; it cannot recall a screenshot or other copy someone already kept.

Keep coaching specific and constructive: describe the observed behavior, the expected standard, and a useful next step. Check the source evidence rather than treating an AI suggestion as an established finding.
