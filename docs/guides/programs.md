# Set up a program and its people

A program defines who reviews which service project and the quality standard they use. Use a program for a team or service with a shared rubric and review practice.

## Create the draft

Choose **Create program**, enter a meaningful name, choose the service project and time zone, and select reviewers and reviewed agents. The creator becomes the first manager.

The time zone controls period dates, including daylight-saving changes. The service project and time zone cannot be changed later; create a new program if either needs to change.

## Add the right people

Open **Program settings → People** and update reviewers and reviewed agents. Save the changes with **Save people**. Use the program's manager controls when responsibility for managing it changes.

Check access in Jira before assigning work. A program role does not grant access to requests or internal comments, and self-review is prevented even when the person is a program manager.

Keep the reviewed-agent roster accurate: it affects whose tickets are considered and the meaning of per-agent coverage.

## Publish and activate

Review the five starter criteria in **Program settings → Review criteria**. [Edit and publish the rubric](criteria.md), then return to **Home** and activate the program when the setup checks pass.

The readiness checklist helps distinguish a saved draft, published criteria, an active program, and available reviews. These are separate steps.

## Keep the program useful

- Review participation when staff or Jira permissions change.
- Publish a new criteria version when standards change; preserve the meaning of existing reviews.
- Use [periods](periods.md) to group recurring samples and compare outcomes.
- Use the supported lifecycle actions when a program is no longer in use. Archiving is different from permanent deletion.

Before deleting a program, read [Data and retention](../administration/data.md) and export any authorized completed results you need to retain. Deletion includes retained review history and cannot be undone through the app.
