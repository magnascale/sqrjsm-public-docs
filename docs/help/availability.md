# Availability and policies

## Product availability

This portal documents **Service Quality Review for Jira Service Management**, by Magnascale. The app appears inside Jira as **Service Quality Review**.

The app is available through [Atlassian Marketplace](https://marketplace.atlassian.com/apps/820182069/service-quality-review-for-jira-service-management). An authorized Atlassian administrator installs it and completes the applicable consent and licensing steps. See [Installation](../getting-started/installation.md).

Screenshots use synthetic example data. Names, requests, and results shown there are illustrative, not customer endorsements or production records.

## About this documentation site

This is a public static site hosted on GitHub Pages. It requires no customer login and contains no live customer review data. Site search runs in the browser against the documentation index. The site adds no analytics, advertising scripts, contact form, or embedded external product session. Fonts and screenshots are served with the site.

GitHub's handling of visits to its hosted services is described in the [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). If you open a linked external service or contact support, that service's applicable policies also apply.
