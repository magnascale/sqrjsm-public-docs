# Glossary

| Term | Meaning |
| --- | --- |
| Program | A team's service project, review criteria, people, and review practice. |
| Rubric / review criteria | Published questions, instructions, response scales, weights, and evidence guidance used to assess a request. |
| Rubric version | A preserved publication of the criteria. Existing reviews keep their assigned version. |
| Period | A group of requests selected from a population window for review. |
| Population window | The date range defining which requests are considered for sampling. |
| Sample | The selected requests for a period, preserving their selection methods. |
| Random selection | A reproducible selection by chance from eligible requests. |
| Coverage selection | Requests added toward a minimum per reviewed agent. Different from assessed coverage. |
| Targeted selection | Requests chosen because they match a specified rule. |
| Manual inclusion | A request explicitly included in a period sample, labelled separately in reports. |
| Standalone review | A chosen ticket reviewed outside a period. It does not enter period reports. |
| Reviewed agent | The person recorded as responsible for the ticket being assessed. |
| Submitted review | A saved human assessment preserved as a submitted revision. |
| N/A | A criterion does not apply. Excluded from applicable assessed coverage. |
| Not enough evidence | A criterion applies but the available record cannot establish an outcome. Neither a pass nor a fail. |
| Assessed coverage | The share of applicable criterion weight that could be assessed from evidence. |
| Provisional result | A result for an open period that may change as work is submitted or corrected. |
| Calibration | Independent blind human assessments of the same evidence, followed by reveal and discussion. Separate from ordinary review counts. |
| Finding | A recorded issue or improvement connected to evidence across reviews or periods. |
| Corrective work | Separately confirmed Jira work created to act on a finding. |
| Coaching summary | Feedback a manager deliberately releases to an agent, separate from the private review. |
| Updates | The in-app inbox for assignments, reminders, and program work needing attention. |
| Former user | A replacement label used when a closed Atlassian account's identity is redacted while permitted history remains. |
